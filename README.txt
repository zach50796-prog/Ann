ANN BIRTHDAY WEBSITE
=====================

Files:
- index.html

The website is completely self-contained. No photo or extra files are required.

GitHub Pages:
1. Upload index.html to your GitHub repository.
2. Commit the file to the main branch.
3. Go to Settings > Pages.
4. Source: Deploy from a branch.
5. Branch: main
6. Folder: /(root)
7. Save.

Then open the Pages link GitHub provides.
